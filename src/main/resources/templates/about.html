바둑 기보 AI 분석기

업로드한 내 바둑 기보를 KataGo(AlphaGo 계열 오픈소스 엔진)로 분석해, 초반·중반·종반 구간별 실력을 수치화하고 프로 기보와 비교합니다. AI 최선수·집 예측·실수 지점을 직관적으로 복기하고, 그 국면에서 AI와 직접 이어 둘 수 있습니다.

KataGo Analysis Engine 연동

엔진의 analysis 모드와 ProcessBuilder로 통신 — 기보 전체를 JSON 쿼리로 보내고 수별 승률·집·최선수·예상수순을 파싱. 실시간 대국은 영구 프로세스를 재사용해 매 착수 지연을 줄였습니다.

GIB / SGF 파서 & 좌표 변환

타이젬 .gib와 .sgf를 직접 파싱해 착수 목록으로 변환. SGF 좌표 ↔ GTP 좌표 변환, 보드 크기(SZ)·대국자·핸디캡까지 처리합니다.

하이브리드 분석 쿼리

형세 변동은 매 수 visits=1, 실력 지표는 10수마다 visits=30 — 한 세션에서 두 종류 쿼리를 섞어 정확도와 속도를 절충했습니다.

집(영역) 예측 히트맵

includeOwnership로 받은 361칸 소유 예측을 바둑판에 확신도 비례 오버레이. 흑/백 관점을 reportAnalysisWinratesAs=BLACK에 맞춰 정규화했습니다.

복기 ↔ 대국 연결

복기 국면을 그대로 대국으로 넘겨 이어 두기. 차례 판정을 수순 파리티가 아닌 "마지막 수의 반대 색"으로 계산해 백선착·접바둑 국면도 정확히 처리합니다.

사활 문제 생성 파이프라인

공개 사활 SGF를 로컬 KataGo로 정답 검증(최선수와 1.5집 이내만 채택)하고 정해 수순 길이로 난이도를 3등분해 60문제를 생성했습니다.

설계 결정 & 한계
개인 포트폴리오 프로젝트입니다. KataGo는 GPU 연산 부담이 커서 상용 배포 대신 엔진을 로컬에서만 구동하고 강한 신경망(b28)을 고정으로 씁니다. 분석 결과는 DB 대신 JSON 파일로 저장해 구조를 단순화했습니다. 실시간 분석·대국은 로컬 실행이 필요하지만, 이미 계산된 복기 결과·실력 리포트는 연산 없이 열람 가능해 정적 데모로 분리할 수 있습니다.
