바둑 AI 기보 분석 웹앱 — 기능 명세 (디자인 의뢰용)
================================================================

■ 프로젝트 개요
----------------------------------------------------------------
KataGo(바둑 AI)를 로컬 엔진으로 연동해, 사용자의 바둑 기보를
수(手) 단위로 분석하고 실력 리포트로 보여주는 Spring Boot 웹앱.
개인 포트폴리오용. 한국어 UI.

- 스택: Spring Boot 4.1 / Java 21 / Thymeleaf(서버사이드 렌더링) /
  Spring Security / KataGo TensorRT 엔진(GPU) / 파일 기반 저장(JSON, DB 없음)
- 바둑판·차트는 전부 HTML5 Canvas로 직접 그림 (외부 차트 라이브러리 없음)


■ 화면(페이지) 목록과 기능
================================================================

1. 로그인 / 회원가입  (/login, /register)
----------------------------------------------------------------
- 아이디·비밀번호 로컬 회원가입/로그인, 로그인 유지(14일 쿠키)
- 소셜 로그인: 구글·네이버 OAuth
- 히어로 배너 + 로그인 카드 형태.
- 미로그인 시 모든 페이지 접근 차단(로그인 게이트)

2. 메인 허브  (/  home.html)
----------------------------------------------------------------
- 로그인 후 첫 화면. 사용자 인사 히어로 배너 + 기보복기 CTA
- 기능 타일 6종: 실력리포트 / 기보복기 / 오답노트 / 갤러리 / AI대국 / 소개
- 최근 분석 결과 4건 카드
- 상단 네비: 브랜드 로고 + 사용자 메뉴 드롭다운(아바타·이름·이메일·로그아웃)

3. 기보 목록 / 분석 시작  (/game  index.html)
----------------------------------------------------------------
- 저장된 기보를 프로기보 / 나의기보 탭으로 구분해 리스트
- 기보 선택 → "분석 시작" (비동기 분석 작업 시작)
- 분석 완료된 기보는 배지 클릭 시 결과 화면으로 바로 이동
- 전체 재분석(일괄) 기능 + 진행률 바
- 파일 업로드(GIB), 타이젬 연동 가져오기

4. 분석 대기 화면  (/game/waiting/{id}  waiting.html)
----------------------------------------------------------------
- 분석 진행률 폴링 표시
- 대기 중 사활(問題) 풀이 위젯 (타이젬 스타일):
  난이도별 랜덤 사활 문제, 정답 축하 오버레이, 이전/다음 문제,
  정답 보기 — 체감 대기시간 감소용

5. ★ 실력 리포트 / 복기 결과  (/game/result/{id}  result.html) — 프로젝트 핵심
----------------------------------------------------------------
분석 결과를 읽는 메인 화면. 구성:
- 헤더 메타: 파일명·날짜·총수·엔진·정밀도(visits)·분석 소요시간
- 한 줄 총평 배너: 최종 형세 + 승부 분기점 + 최대 실수/호수를 자동 문장화
  (수번 클릭 시 이동)
- 승부 흐름 그래프: 흑 승률 추이 라인차트. 실수·악수·패착·현재수 마커,
  클릭 시 해당 수로 이동
- 예상 기력: 착수 정밀도 기반 급수대 추정(흑/백 각각)
- 구간별 카드(초반/중반/종반): 최선수 일치율 게이지, 평균 집손해, 실수/악수 개수
- 인터랙티브 바둑판(Canvas): 수 이동 내비게이션, 실시간 승률 바,
  AI 예상 집(영역) 히트맵, AI 추천수 표시, 변화도,
  내 수 vs AI 최선수 나란히 비교 모달, 직접 놓아보기,
  이 수부터 AI와 다시 두기
- AI 착수 통계: 흑·백 최선수 일치율 + 수 품질 분포 차트
- 패착(승부의 분기점) 콜아웃
- 핵심 실수 리스트 (클릭 시 바둑판 이동)
- 이 판의 호수(好手) 카드 (잘 둔 수, 클릭 이동)
- 주석 SGF 다운로드 (등급·집손해·최선수 코멘트 포함)

6. AI 대국  (/play  play.html)
----------------------------------------------------------------
- KataGo와 직접 대국. 흑/백 선택, 착수·패스·무르기
- AI 힌트(추천수 5개, 승률·예상 집차), 실시간 승률 그래프 바(승률+집차)
- 복기 화면에서 특정 국면 이어두기 가능

7. 실시간 분석판  (/study  study.html)
----------------------------------------------------------------
- 빈 판에 흑·백을 직접 놓으며 매 수 AI 추천수·승률을 실시간 확인
  (대국 없이 연구용)
- 추천수 상위 5개(승률·집차), 무르기·패스·전체지우기, 실시간 승률 그래프 바

8. 오답노트  (/notes)
----------------------------------------------------------------
- 여러 기보에서 반복되는 실수 패턴을 모아 보여주는 학습 페이지

9. 갤러리  (/gallery)
----------------------------------------------------------------
- 분석한 기보들을 카드형으로 모아보기

10. 배치 분석  (/analysis/batch)
----------------------------------------------------------------
- 여러 기보 실력 지표를 집계해 보여주는 대시보드

11. 소개  (/about)
----------------------------------------------------------------
- 프로젝트/기능 설명 페이지


■ 핵심 기술 기능 (분석 엔진)
================================================================
- 수 단위 분석: 각 착수마다 승률 변화·집(점수) 손해·최선수 대비 등급 계산
  · 등급: 최선 / 좋음 / 보통 / 실수 / 악수 (집 손실 기준)
  · 구간: 초반(≤50수) / 중반(51~150수) / 종반(151수~)
- 2차 정밀 재분석: 실수·악수로 잡힌 국면만 고정밀도로 다시 분석해 오판 교정
- AI 예상 집(영역) 예측: 361칸 흑/백 소유 확률 히트맵
- AI 추천수 + 예상 진행(변화도) 제공
- 승률·집차 실시간 형세 판단
- 비동기 분석(백그라운드 작업 + 진행률 폴링), 전체 일괄 재분석
- 입력 포맷: GIB(타이젬), SGF 파싱 지원, 주석 SGF 출력


■ 데이터 / 인증 (참고)
================================================================
- DB 없음 — 기보 원본은 로컬 폴더의 .gib/.sgf,
  분석 결과는 {uuid}.json 파일로 저장
- 회원 계정은 JSON 파일(BCrypt 해시), 로그인 유지 쿠키
- 사활 문제 75개 번들(공개 고전 사활, 쉬움/보통/어려움)


■ 디자인 시 참고할 특징
================================================================
- 한국어 UI, 바둑 초보~중급 일반 사용자 대상
  (전문 용어보다 직관적 표현 선호)
- 한게임/타이젬 같은 국내 바둑 포털 톤 지향
- 바둑판·그래프는 Canvas 렌더 → 색상·마커·폰트 지정이 디자인 핵심
- 정보 밀도가 높음(리포트 페이지) → 읽는 순서·시각적 우선순위 정리 필요
- 색 의미 관례:
  흑=검정, 백=흰색, 실수=주황, 악수=빨강, 패착=노랑, 좋은 수=초록
