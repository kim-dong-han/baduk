# 스크린샷 촬영 가이드

| 파일명 | 캡처할 화면 | 팁 |
|---|---|---|
| `review-heatmap.png` | `/game` → 결과 보기 → 종반 수로 이동 후 **"집예측"** 토글 ON | 종반(150수 이후)일수록 흑/백 영역이 선명 |

| `about.png` | `/about` (기술 소개) | 상단 히어로 + 기능 카드 |

권장: PNG, 폭 1200~1600px. 파일명을 위와 동일하게 맞추면 README가 그대로 표시됩니다.
